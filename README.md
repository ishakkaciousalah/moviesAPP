# 🎬 Movie Explorer App

A simple responsive movie gallery built with HTML, CSS, and JavaScript.

## 🚀 Features
- Movie cards with poster, title, and year
- Responsive grid layout
- Live search filter
- Smooth hover animations

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
